A tiny Node program that writes a two-line explanation of an everyday thing — a queue — to a 10-year-old. Line 1 explains the queue with one vivid analogy (a human train); line 2 says honestly what that analogy maps and what it leaves out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
